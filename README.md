# Few-shot 예시 폴더

이 폴더의 마크다운 파일은 보도자료 생성 시 모델에게 "톤·문장 호흡·전개 구조"를 학습시키기 위한 예시입니다.

## 파일 구조

각 파일은 다음 세 섹션을 가져야 합니다:

```markdown
# 주제목
(한 줄)

# 부제목
(한 줄)

# 본문
(여러 단락. 단락 사이는 빈 줄로 구분)
```

## 카테고리 ↔ 파일명 매핑

| 카테고리 | 파일명 |
|---|---|
| 입시, 모집 | `입시_모집.md` |
| 학생 | `학생.md` |
| 교육, 행정 | `교육_행정.md` |
| 지역사회, 산학협력 | `지역사회_산학협력.md` |
| 국제, 글로벌 | `국제_글로벌.md` |
| 대학 성과 | `대학_성과.md` |

## 편집 시 유의사항

- **사실 정보 포함 OK**: 예시 본문에는 구체 사실(연도·인물명·수치)이 들어가도 됩니다. 모델은 이걸 "베끼지 말고 구조만 학습하라"는 지시를 함께 받습니다.
- **종료된 사업은 교체 권장**: 예시가 너무 오래된 사건이면 비슷한 톤의 최근 사건으로 교체하세요.
- **새 카테고리 추가**: 새 파일을 만든 뒤, 메인 코드 `FEW_SHOT_FILES` 매핑에 한 줄 추가하면 사이드바 드롭다운에 자동 노출됩니다.

## 향후 확장 (Phase 4 예정)

카테고리당 여러 예시를 두고 매번 랜덤 샘플링하려면 파일명 뒤에 번호를 붙이세요:
- `학생_01.md`, `학생_02.md`, `학생_03.md` …

이 구조가 활성화되면 로더가 자동으로 같은 prefix의 파일들을 모아 매번 1개를 무작위 선택합니다.
